# Chess Game

A simple, interactive chess game built with vanilla HTML, CSS, and JavaScript.

## Features

- ♟️ Full chess board with all pieces
- 🎯 Turn-based gameplay (White vs Black)
- ✅ Move validation for all piece types
- 👑 Check detection
- 📜 Move history tracking
- 🎨 Modern, responsive UI
- 🔄 Board flip option
- 🆕 New game functionality

## How to Play

1. Open `index.html` in your web browser
2. Click on a piece to select it (highlighted in blue)
3. Click on a valid destination square (highlighted in green) to move
4. The game alternates between White and Black turns
5. When in check, the king's square will be highlighted in red
6. Use "New Game" to start over
7. Use "Flip Board" to rotate the board view

## Piece Movement Rules

- **Pawn**: Moves forward one square (two on first move), captures diagonally
- **Rook**: Moves horizontally or vertically any number of squares
- **Knight**: Moves in an L-shape (2 squares in one direction, 1 square perpendicular)
- **Bishop**: Moves diagonally any number of squares
- **Queen**: Combines rook and bishop movement
- **King**: Moves one square in any direction
